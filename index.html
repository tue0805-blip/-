🏫 학급 관리

학급을 전환해도 각 학급의 명단과 추첨 기록이 따로 저장됩니다.

📥 명단 일괄 입력

한 줄에 한 명씩 작성하거나, 엑셀에서 복사한 ‘번호 / 이름’ 두 열을 붙여넣으세요.

CSV: 번호, 이름, 제외 여부(선택). CSV 파일은 UTF-8 또는 일반적인 한국어 엑셀 인코딩을 지원합니다. 기존 명단을 바꾸기 전에 확인창이 표시됩니다.

📝 학생 명단

결석·제외 학생은 체크하면 모든 새 추첨 및 편성에서 제외됩니다.

번호이름추첨 제외삭제

번호·이름을 수정한 후 다른 칸을 클릭하면 자동 저장됩니다. 제외 표시를 해제하면 즉시 다시 대상에 포함됩니다.

🕓 추첨 및 편성 기록

학급별로 최대 300건까지 이 브라우저에 저장됩니다. 시간이 기록됩니다.

🔒 학생 정보는 이 기기의 브라우저 저장소에만 보관됩니다. 외부 서버·로그인·CDN·API 통신을 사용하지 않습니다. 다른 기기로 옮길 때는 CSV를 이용하세요.

⌨️ 사용 방법과 단축키

추첨 대상에서 제외할 학생은 명단 관리에서 체크하세요. 중복 방지 시에는 이미 선정된 학생이 빠집니다.

  • Space / Enter : 학생 뽑기 / 룰렛 돌리기
  • → : 다음 발표자
  • Ctrl + Z : 최근 동작 실행 취소 (Mac은 ⌘Z)
  • ? : 이 도움말 보기
  • Esc : 도움말 / 전체 화면 종료

편집창에 글자를 쓰는 중에는 단축키가 작동하지 않습니다. 실행 취소는 이 페이지가 열려 있는 동안 학급별로 지원됩니다.
